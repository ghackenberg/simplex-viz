Dimensionality reduction tools such as UMAP and t-SNE excel at revealing raw density clouds, yet struggle as interactive application interfaces: points overlap unpredictably, cluster boundaries drift across updates, and axes carry no explicit semantic anchors.

## Embedding Centroids onto a Regular 60° Graph

Rather than scattering centroids arbitrarily across `ℝ²`, SimplexViz separates **macro-topology** from **micro-positioning**:

1. **Multi-Modal Spherical k-Means++** extracts `K` balanced cluster prototypes from one or multiple weighted feature vectors (`EmbeddingSource[]`).
2. **Quadratic Assignment Simulated Annealing** embeds those `K` prototypes onto the `K` vertices of an equilateral triangle mesh so cosine similarity aligns with 1-hop mesh edges.
3. **Closed-Form Planar Simplex Projection** projects each item `x` onto the single planar triangle `τ = (c₁, c₂, c₃)` minimizing constrained NNLS reconstruction error—or distributes items smoothly via temperature-scaled Soft-Simplex weights (`triangleSpread`).
