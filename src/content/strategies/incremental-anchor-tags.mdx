## Zero-Reshuffle Streaming Updates

On `initialize()`, **Incremental Tag Anchoring** establishes the initial `K`-vertex topic layout via QAP annealing. On subsequent `update()` calls (when items are added or removed without changing mesh dimensions), it freezes existing vertex assignments and routes newly discovered tags to the vertex with highest co-occurrence affinity—guaranteeing maximum spatial mental-map stability.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createIncrementalAnchorClusteringStrategy,
  createWarmStartPbdLayoutStrategy,
} from '@simplex-viz/react';

<SimplexTopicGraph
  items={liveStreamItems}
  clusteringStrategy={createIncrementalAnchorClusteringStrategy()}
  layoutStrategy={createWarmStartPbdLayoutStrategy()}
/>;
```
