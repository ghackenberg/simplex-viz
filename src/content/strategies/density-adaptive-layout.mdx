## Post-Dispersion Smooth Crowd-Density Scaling

Whereas **Collision-Local Pocket Layout** shrinks strictly those pairs that touch during relaxation, **Density-Adaptive Layout** pairs `createMeshInwardFanSeeder()` and `createSpaceFillingPbdRelaxer()` with `createDensityPriorScaleController()`. Co-located anchors first fan out across the open interior of their covering mesh triangles at `1.0x`; a smooth radial spatial kernel (`crowdRadiusPx`) then measures true post-dispersion crowding so moderate pockets that fit comfortably stay at `1.0x`, while genuinely congested hubs exhibit gradual core-to-fringe size transitions polished locally (`0.0 px` convex SAT clearance, zero global collateral shrink).

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createLocalAdaptiveLayoutStrategy,
} from '@simplex-viz/react';

<SimplexTopicGraph
  items={items}
  layoutStrategy={createLocalAdaptiveLayoutStrategy({
    crowdRadiusPx: 84,
    minLocalScale: 0.35,
  })}
/>;
```
