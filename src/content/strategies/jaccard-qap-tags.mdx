## Jaccard Tag Partitioning &amp; QAP Simulated Annealing

**Jaccard Annealing Clustering** builds a regularized tag co-occurrence graph, partitions tags into `K` balanced clusters, and solves a **Quadratic Assignment Problem (QAP)** via deterministic Simulated Annealing so strongly co-occurring clusters sit on 1-hop adjacent mesh vertices. Across updates, the **Hungarian algorithm** matches new clusters to prior vertices to preserve cluster UIDs and OKLab colors.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createJaccardAnnealingClusteringStrategy,
} from '@simplex-viz/react';

const jaccard = createJaccardAnnealingClusteringStrategy({
  sharedTagRule: 'planar-hitting-set',
  anchorRule: 'explaining-away',
});

<SimplexTopicGraph items={items} clusteringStrategy={jaccard} />;
```
