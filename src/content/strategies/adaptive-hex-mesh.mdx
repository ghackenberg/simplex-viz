## How Adaptive Hex Lattice Works

**Adaptive Hex Lattice** evaluates candidate staggered hexagonal grids `(rows, cols, orientation, wideFirst)` for the active cluster budget `K` (informed by `clusteringStrategy.estimateClusterCount` or tag diversity, clamped to `[3, maxClusters]`).

Every face in the generated mesh is an exact **60° equilateral triangle** with height `h = s · √3 / 2`. Evaluating both horizontal and vertical primary axes—and whether even or odd rows carry the extra vertex (`wideFirst`)—maximizes usable canvas area and aspect-ratio alignment across widescreen, square, and portrait mobile viewports without distorting barycentric angles.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createAdaptiveHexMeshStrategy,
} from '@simplex-viz/react';

const meshStrategy = createAdaptiveHexMeshStrategy({
  innerPadding: 56,
  minSideLength: 160,
  maxClusters: 10,
});

<SimplexTopicGraph items={items} meshStrategy={meshStrategy} />;
```
