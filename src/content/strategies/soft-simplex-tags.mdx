## Continuous Interior Spreading + Unconstrained Halos

Discrete tag assignment snaps 2-cluster items onto exact edge midpoints and 3-cluster items onto exact triangle centroids. **Soft-Simplex Tag Clustering** blends tag specificity across the best covering planar triangle `τ = (c₁, c₂, c₃)` controlled by `triangleSpread`, utilizing the 2D triangle area naturally while keeping 1-cluster items (`unitVertexIndices.length === 1`) completely free to fan around their anchor in 360°.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createSoftSimplexTagClusteringStrategy,
} from '@simplex-viz/react';

const tagClustering = createSoftSimplexTagClusteringStrategy<Article>({
  getTags: (article) => article.hashtags,
  triangleSpread: 0.45,
  sharedTagRule: 'planar-hitting-set',
  anchorRule: 'explaining-away',
});

<SimplexTopicGraph items={articles} clusteringStrategy={tagClustering} />;
```
