## Seamless Light &amp; Dark Theme Parity

Colors optimized for dark backgrounds (`L ≈ 0.74`) wash out against white surfaces, while colors darkened for white surfaces look murky on `#07090E`. **Theme-Adaptive OKLab** inspects the active `theme` (`'light' | 'dark'`) passed to `<SimplexTopicGraph />` or `SimplexSvgController`, shifting OKLab lightness `L` while preserving hue angle `h = atan2(b, a)` so every cluster keeps its recognizable identity across theme switches.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createThemeAdaptiveOklabColorStrategy,
} from '@simplex-viz/react';

const adaptiveColors = createThemeAdaptiveOklabColorStrategy();

<SimplexTopicGraph
  items={items}
  theme={isDark ? 'dark' : 'light'}
  colorStrategy={adaptiveColors}
/>;
```
