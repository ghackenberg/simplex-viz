## Minimal Node Displacement Across Live Mutations

Re-seeding every item from scratch when a single new record arrives can cause unnecessary local swaps among neighboring nodes. **Warm-Start PBD Layout** wraps `createMeshInwardFanSeeder()` with `withWarmStartSeeder(...)` and pairs it with `createSpaceFillingPbdRelaxer()`: existing item IDs start relaxation from their exact previous-frame `(x, y)` coordinates, so only nodes directly displaced by the newcomer shift smoothly out of the way.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createIncrementalAnchorClusteringStrategy,
  createWarmStartPbdLayoutStrategy,
} from '@simplex-viz/react';

<SimplexTopicGraph
  items={streamingItems}
  clusteringStrategy={createIncrementalAnchorClusteringStrategy()}
  layoutStrategy={createWarmStartPbdLayoutStrategy()}
/>;
```
