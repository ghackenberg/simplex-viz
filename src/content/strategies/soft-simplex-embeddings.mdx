## Multi-Modal Vector Fusion &amp; Contrastive Cluster Naming

**Soft-Simplex Embedding Projection** L2-normalizes and weights one or more embedding modalities into a unified feature vector, runs load-balanced Spherical/Euclidean k-Means++, embeds the learned centroid affinity matrix onto the 60° mesh via QAP annealing, and projects items continuously onto their optimal planar triangle `τ = (c₁, c₂, c₃)`.

When `features` are supplied, SimplexViz scores each cluster against corpus-wide base rates—suppressing ubiquitous majority categories (such as a 77% `"Drama"` baseline in cinema catalogs) while automatically disambiguating sibling clusters that split a shared taxonomic group via intra-group secondary traits (for example *Adélie · Male* vs. *Adélie · Female*).

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createSoftSimplexEmbeddingClusteringStrategy,
} from '@simplex-viz/react';

const mediaClustering = createSoftSimplexEmbeddingClusteringStrategy<MediaAsset>({
  getEmbedding: [
    { name: 'Scene', getVector: (m) => m.sceneVec, weight: 0.65 },
    { name: 'Style', getVector: (m) => m.styleVec, weight: 0.35 },
  ],
  features: [
    { label: 'Budget', getValue: (m) => Math.log10(m.budgetMusd), highLabel: 'Big-Budget Epics', lowLabel: 'Low-Budget Cult' },
    { label: 'Runtime', getValue: (m) => m.runtimeMin, highLabel: 'Epic Runtime', lowLabel: 'Compact Classics' },
  ],
  clusterCount: 7,
  metric: 'cosine',
  triangleSpread: 0.45,
});

<SimplexTopicGraph items={assets} clusteringStrategy={mediaClustering} />;
```
