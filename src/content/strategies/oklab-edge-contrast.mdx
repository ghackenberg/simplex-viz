## Graph-Coloring Contrast &amp; Chroma-Preserving Mixing

**OKLab Edge Contrast** generates a uniform ring of perceptual hues in Björn Ottosson's OKLab space, seeds vertices greedily, and runs pairwise swap refinement to maximize the minimum perceptual distance `ΔE_OK` across all mesh edges. Multi-cluster bridge items interpolate linearly in `(L, a, b)` with chroma restoration so 50/50 edge midpoints remain vivid rather than collapsing to muddy sRGB grey.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createOklabContrastColorStrategy,
} from '@simplex-viz/react';

<SimplexTopicGraph
  items={items}
  colorStrategy={createOklabContrastColorStrategy({
    lightness: 0.74,
    chroma: 0.15,
  })}
/>;
```
