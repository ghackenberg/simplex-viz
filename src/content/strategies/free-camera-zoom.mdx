## Continuous Affine Camera Navigation

**Continuous Free Camera** sets `mode: 'free-camera'`, enabling smooth cursor-centered mouse-wheel zoom (`onWheel: 'zoom-to-cursor'`), click-and-drag panning, two-finger touch pinch-zoom, and single-click cluster/triangle spotlight highlighting without subdividing triangles into child frames.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createFreeCameraZoomStrategy,
} from '@simplex-viz/react';

<SimplexTopicGraph
  items={items}
  zoomStrategy={createFreeCameraZoomStrategy({
    minZoom: 0.5,
    maxZoom: 5.0,
  })}
  onWheel="zoom-to-cursor"
/>;
```
