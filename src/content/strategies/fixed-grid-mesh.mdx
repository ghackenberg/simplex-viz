## Deterministic Fixed Topology

Whereas **Adaptive Hex Lattice** adjusts vertex count dynamically, **Fixed Grid Lattice** locks the exact planar graph `(cols × rows)` across every resize. By default (`orientation: 'auto'`), the grid aligns its longer axis with the canvas aspect ratio (landscape vs. mobile portrait) while scaling the equilateral side length `s` to fill the container—or keeping `s` constant when `sideLength` is explicitly specified.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createFixedLatticeMeshStrategy,
} from '@simplex-viz/react';

// Exact 3 × 3 = 9 topic vertices in horizontal 60° rows:
const fixedNine = createFixedLatticeMeshStrategy({
  cols: 3,
  rows: 3,
  orientation: 'horizontal',
  wideFirst: true,
});

<SimplexTopicGraph items={items} meshStrategy={fixedNine} />;
```
