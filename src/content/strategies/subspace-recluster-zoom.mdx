## Local Variance Projection & Exact `6!` Sub-Mesh QAP

Purely geometric `1:4` subdivision preserves parent barycentric ratios, which works well as a baseline—but inside a specialized region (for example a *Mammals* triangle in **UCI Zoo** or a *Blockbuster* triangle in **Vega Cinema**), the features that formed the root overview are already locally constant (`milk = true`, `backbone = true` → `σ_local = 0`).

`createSubspaceZoomStrategy` solves a genuine **local subspace re-clustering problem** at every drill-down step while preserving conformal `1:4` equilateral geometry:

1. **Zero-Variance Projection**: Evaluates candidate boolean, categorical, numeric, vector, or similarity axes exclusively over the subset `S` of items inside the focused triangle or cluster. Any attribute that is constant across `S` (`σ_local ≤ 10⁻⁶`) drops out automatically, promoting intra-group variations (such as *Predator*, *Aquatic*, *Body Size*, *Budget*, or *Release Era*).
2. **Local `k`-Means++ & Distinct Facet Labeling**: Partitions `S` into up to `6` local prototypes (or `3` prototypes for a cluster spotlight) and assigns collision-free, human-readable `subclusterLabel`s ranked by standardized z-score separation.
3. **Exact `6! = 720` Permutation Alignment**: Evaluates all `720` bijections mapping the `6` local prototypes onto `[V₀, V₁, V₂, M₀₁, M₁₂, M₂₀]` to jointly maximize parent-corner spatial continuity, `9`-edge QAP cosine similarity, and degree-4 midpoint load balance.
4. **Parent-Context Orientation Plaques**: The `3` outer corners (`V₀, V₁, V₂`) retain their parent corner's `parentContextLabel` as a compact header line above the newly discovered local `subclusterLabel` (for example `EPIC RUNTIME / New Hollywood`), while the `3` edge midpoints (`M₀₁, M₁₂, M₂₀`) render as single-line chamfered sub-cluster plaques alongside color-coded `ZoomBreadcrumbSegment` breadcrumbs.
5. **Uniform Cluster/Subcluster Stars & Single-Triangle Leaf Focus**: Clicking any cluster or subcluster badge opens its lattice-conformal 1-ring `'incident-star'` with continuous simplex-distance item dimming (`opacity = 0.32 + 0.68 · w̃₀`), and clicking the free background face of a `1.0×` leaf triangle focuses that single un-subdivided triangle (`'triangle-focus'`) while keeping its items directly clickable.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createCollisionDrivenLayoutStrategy,
  createSubspaceZoomStrategy,
} from '@simplex-viz/react';

const zoomStrategy = createSubspaceZoomStrategy<FilmRecord>({
  features: [
    {
      label: 'Budget',
      getValue: (f) => Math.log10(f.budgetMusd),
      highLabel: 'High Budget',
      lowLabel: 'Low Budget',
    },
    {
      label: 'Release Era',
      getValue: (f) => f.releaseYear,
      highLabel: 'New Hollywood',
      lowLabel: 'Golden Age',
    },
    {
      label: 'Genre',
      getValue: (f) => f.genre,
    },
  ],
  clusterZoomMode: 'incident-star',
});

<SimplexTopicGraph
  items={films}
  layoutStrategy={createCollisionDrivenLayoutStrategy()}
  zoomStrategy={zoomStrategy}
  showZoomBreadcrumbs
/>;
```
