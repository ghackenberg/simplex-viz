## Closed-Form Planar NNLS Projection

For each item vector `x`, **Planar NNLS Embedding Projection** evaluates every candidate planar simplex `τ` (vertices, 1-hop mesh edges, and 60° mesh triangles) and solves the exact constrained quadratic program minimizing `|| x − ∑ w_i · μ_i ||₂²` subject to `w_i ≥ 0` and `∑ w_i = 1`. Selecting the planar simplex with lowest reconstruction residual guarantees faithful geometric interpolation without cross-mesh tangling, while optional `features` automatically synthesize contrastive, collision-free labels across all `K` vertices.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createEmbeddingClusteringStrategy,
} from '@simplex-viz/react';

const nnlsProjection = createEmbeddingClusteringStrategy<DocVector>({
  getEmbedding: (doc) => doc.embedding,
  clusterCount: 8,
  metric: 'cosine',
  anchorRule: 'simplex-projection',
});

<SimplexTopicGraph items={docs} clusteringStrategy={nnlsProjection} />;
```
