## Partitioning Around Medoids (PAM) on 60° Meshes

**Pairwise k-Medoids Projection** builds the symmetric `N × N` similarity matrix, selects `K` real domain items as cluster medoids via deterministic farthest-first initialization plus PAM swap refinement, embeds inter-medoid similarity onto the 60° mesh via QAP annealing, and projects every item onto its closest planar medoid triangle. Supplying `features` (or `deriveLabel`) turns medoid neighborhoods into concise, pairwise-distinct taxonomic or domain badges rather than raw exemplar IDs.

## Usage Example

```tsx
import {
  SimplexTopicGraph,
  createSimilarityClusteringStrategy,
} from '@simplex-viz/react';

const kernelClustering = createSimilarityClusteringStrategy<Protein>({
  getSimilarity: (a, b) => computeBlastAlignmentScore(a, b),
  clusterCount: 6,
});

<SimplexTopicGraph items={proteins} clusteringStrategy={kernelClustering} />;
```
