## Quick Usage in Plain HTML, Astro, Vue, Svelte, or Angular

Import `@simplex-viz/wc/define` once to register `<simplex-topic-graph>`, or call `defineSimplexTopicGraphElement()` explicitly for SSR-safe manual control:

```html
<simplex-topic-graph
  id="atlas"
  preset="badges"
  theme="dark"
  reduced-motion="auto"
  tooltip
  style="width: 100%; height: 520px;"
></simplex-topic-graph>

<script type="module">
  import '@simplex-viz/wc/define';

  const el = document.getElementById('atlas');
  el.items = [
    { id: '1', label: 'Simplex Geometry', tags: ['geometry', 'topology'] },
    { id: '2', label: 'Color Spaces', tags: ['color', 'perception'] },
    { id: '3', label: 'OKLab Mixing', tags: ['geometry', 'color'] },
  ];

  el.addEventListener('simplex-click', (e) => {
    console.log('Clicked:', e.detail);
  });

  el.addEventListener('simplex-selection-change', (e) => {
    console.log('Selected IDs:', e.detail.ids);
  });
</script>
```

## Inline JSON Data (HTML-Only)

For static pages, blogs, or Markdown/Astro embeds without writing imperative JavaScript, place a `<script type="application/json">` child directly inside `<simplex-topic-graph>`:

```html
<simplex-topic-graph preset="geometric" theme="light" tooltip style="height: 460px;">
  <script type="application/json">
    [
      { "id": "a", "label": "Alpha", "tags": ["systems", "design"] },
      { "id": "b", "label": "Beta", "tags": ["design", "math"] },
      { "id": "c", "label": "Gamma", "tags": ["systems", "math"] }
    ]
  </script>
</simplex-topic-graph>
```

## Reactive Attributes & Standard `CustomEvent`s

- **Observed Attributes (24)**: `preset`, `theme`, `renderer` (`'svg'`), `tooltip`, `aria-label`, `keyboard-navigation`, `reduced-motion`, `marquee-selection`, `shift-click-selects`, `show-zoom-breadcrumbs`, `show-hulls`, `empty-cluster-behavior`, `defer-initial-layout`, `item-filter-mode`, `touch-scroll-lock-px`, `click-tolerance-px`, `focus-on-cluster-click`, `focus-on-triangle-click`, `relayout-on-font-load`, `timeline`, `items`, `selected-ids`, `highlighted-ids`, `pinned-ids`.
- **Bubbling & Composed Events**: `simplex-click` *(cancelable via `preventDefault()`)*, `simplex-hover` *(cancelable)*, `simplex-selection-change` (`{ selectedIds, ids }`), `simplex-zoom`, `simplex-timeline-change`, `simplex-metrics`, `simplex-clusters-change`, and `simplex-legend-change` (`SimplexLegendModel`).
- **Imperative Methods**: `getLegendModel()`, `getTimeline()`, `subscribeTimeline()`, `getViewState()`, `restoreViewState()`, `exportSvg()`, `exportPng()`, `setSelectedIds()`, `toggleSelectedId()`, `clearSelection()`, `selectItemsInScreenRect()`, `setHighlightedIds()`, `focusItem()`, `zoomToItem()`, `setItemFilter()`, `drillDownTriangle()`, `drillDownCluster()`, `drillUp()`, `drillToRoot()`, `resetCamera()`, `zoomBy()`, `setReducedMotion()`, `batch()`, `setOptions()`, and `relayout()`.
