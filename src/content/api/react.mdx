## `<SimplexTopicGraph />` Props Overview

`<SimplexTopicGraph />` syncs declarative React prop updates into the underlying `SimplexSvgController` without remounting the SVG scene or interrupting active spring animations:

```tsx
import {
  SimplexTopicGraph,
  createSubspaceZoomStrategy,
  createCollisionDrivenLayoutStrategy,
  createSoftSimplexTagClusteringStrategy,
  useSimplexGraphController,
} from '@simplex-viz/react';

export function InteractiveAtlas({ articles }: { readonly articles: readonly Article[] }) {
  const { controllerRef, handle } = useSimplexGraphController<Article>();

  return (
    <div className="h-[640px] w-full">
      <SimplexTopicGraph
        controllerRef={controllerRef}
        items={articles}
        getId={(a) => a.slug}
        getTags={(a) => a.tags}
        getLabel={(a) => a.title}
        preset="glyphs"
        theme="dark"
        clusteringStrategy={createSoftSimplexTagClusteringStrategy({ triangleSpread: 0.45 })}
        layoutStrategy={createCollisionDrivenLayoutStrategy()}
        zoomStrategy={createSubspaceZoomStrategy()}
        showZoomBreadcrumbs
        itemFilter={(a) => a.tags.length > 0}
        itemFilterMode="dim"
        ariaLabel="Interactive research articles atlas"
        keyboardNavigation
        tooltip
        onZoomStateChange={(state) => {
          console.log('Current drill depth:', state.depth);
        }}
      />
    </div>
  );
}
```

## Imperative Handle Methods (`handle`)

Returned by `useSimplexGraphController()`:

- **Live Corpus Mutations & Filtering**: `handle.addItems(items)`, `handle.removeItems(ids)`, `handle.setItems(items)`, `handle.setItemFilter(predicate, options?)`, `handle.getItemFilter()`
- **Linked-View Search & Navigation**: `handle.setHighlightedIds(ids)` / `handle.setHighlightedItems(ids)`, `handle.getHighlightedIds()` / `handle.getHighlightedItems()`, `handle.focusItem(itemId | null, options?)`, `handle.getFocusedItemId()`, `handle.zoomToItem(itemId, options?)`
- **Client-Side Snapshot Export**: `handle.exportSvg(options?)`, `handle.exportPng(options?)` (`format: 'blob' | 'dataUrl'`, HiDPI `scale`)
- **Atomic Batching & Options**: `handle.batch(fn)`, `handle.setOptions(options)`
- **Hierarchical Drill-Down**: `handle.drillDownTriangle(index)`, `handle.drillDownCluster(uid)`, `handle.drillToNeighbor(neighborId)`, `handle.drillUp()`, `handle.drillToDepth(depth)`, `handle.drillToRoot()`, `handle.getZoomState()`
- **Focus, Accessibility, Camera & Telemetry**: `handle.setFocusedTriangleIndex(index | null)`, `handle.getKeyboardFocusTarget()`, `handle.clearKeyboardFocus()`, `handle.zoomBy(factor)`, `handle.resetCamera()`, `handle.relayout()`, `handle.getMetrics()`, `handle.getClusters()`, `handle.getTimeline()`
