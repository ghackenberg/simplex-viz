## Overview

`@simplex-viz/canvas` renders the entire simplex atlas onto a single HiDPI `<canvas>` with zero per-node DOM overhead, world-space viewport frustum culling, and automatic Level-of-Detail (LOD) shape simplification for corpora of **2,000–10,000+ items** at 60 FPS. It depends exclusively on `@simplex-viz/core` (including pure preset/OKLab/timeline helpers and `@simplex-viz/core/dom` container, tooltip, breadcrumb & timeline HUD overlays, accessibility, and gesture primitives) with zero dependency on `@simplex-viz/svg`, while mirroring `SimplexSvgController`'s full interactive API (`timeline: true` shorthand, `setTimelineOptions`, `subscribeTimeline`, `showZoomBreadcrumbs`, `setZoomUiOptions`, `setOptions`, `batch`, `deferInitialLayout`, `relayoutOnFontLoad`, `onClustersChange`, `onFpsUpdate`, `SimplexDomTooltipRenderer` tooltips, `getKeyboardFocusTarget`, `getInteractiveTargets`, `restoreViewState`) and curated `@simplex-viz/core` root re-exports.

## Interactive Canvas Controller

```ts
import {
  createSimplexCanvas,
  createCollisionDrivenLayoutStrategy,
  createSubspaceZoomStrategy,
} from '@simplex-viz/canvas';

const controller = createSimplexCanvas('#atlas', {
  items: largeCorpus,
  preset: 'badges',
  theme: 'dark',
  lodThresholdPx: 3.5,
  layoutStrategy: createCollisionDrivenLayoutStrategy(),
  zoomStrategy: createSubspaceZoomStrategy(),
  tooltip: true,
});

// Inspect render culling & LOD stats for profiling:
console.log(controller.getRenderStats());

// Native zero-serialization PNG export:
const pngBlob = await controller.exportPng({ scale: 2 });
```

## Pairing with `@simplex-viz/core/worker`

```ts
import { createSimplexWorkerClient } from '@simplex-viz/core/worker';
import { renderSimplexSnapshotToCanvas } from '@simplex-viz/canvas';

const worker = createSimplexWorkerClient(
  () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
);

const { snapshot } = await worker.solve(largeCorpus, {
  width: 1200,
  height: 760,
  layoutStrategy: { kind: 'collision-driven' },
});

renderSimplexSnapshotToCanvas(canvasEl, snapshot, { theme: 'dark' });
```

See this exact pipeline running live on 1,000–3,500 stars in the [Hertzsprung-Russell Stellar Spectral Atlas example](/examples/stellar-spectral-canvas).
