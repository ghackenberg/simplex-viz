## Mounting in Vanilla TypeScript, Vue, Svelte, or Angular

`createSimplexSvg` accepts either a CSS selector (`'#atlas'`) or an `HTMLElement` reference and returns a `SimplexSvgController` whose `.destroy()` method cleans up all DOM listeners and `ResizeObserver` instances:

```ts
import {
  createSimplexSvg,
  createSubspaceZoomStrategy,
  GradientTriangleSvgView,
  ClusterTintedEdgeSvgView,
} from '@simplex-viz/svg';

const controller = createSimplexSvg('#atlas', {
  items,
  preset: 'glyphs',
  theme: 'dark',
  triangleView: new GradientTriangleSvgView({ baseOpacity: 0.16 }),
  edgeView: new ClusterTintedEdgeSvgView({ strokeWidth: 1.35 }),
  zoomStrategy: createSubspaceZoomStrategy(),
  showZoomBreadcrumbs: true,
  tooltip: true,
});

// Clean up on unmount:
// controller.destroy();
```

## Custom `SvgNodeView` Contract

Implement `SvgNodeView<TVisual, TRenderState>` when building high-throughput custom SVG glyphs that update imperatively at 60 fps without virtual-DOM overhead:

```ts
import type { SvgNodeView, ContentNodeRenderState } from '@simplex-viz/svg';

export const pillNodeView: SvgNodeView<
  { label: string; colorHex: string },
  ContentNodeRenderState<{ label: string; colorHex: string }, MyItem>
> = {
  createElement(doc) {
    const g = doc.createElementNS('http://www.w3.org/2000/svg', 'g');
    const rect = doc.createElementNS('http://www.w3.org/2000/svg', 'rect');
    const text = doc.createElementNS('http://www.w3.org/2000/svg', 'text');
    g.append(rect, text);
    return g;
  },
  updateElement(g, visual, state) {
    const [rect, text] = g.children as unknown as [SVGRectElement, SVGTextElement];
    rect.setAttribute('x', '-42');
    rect.setAttribute('y', '-12');
    rect.setAttribute('width', '84');
    rect.setAttribute('height', '24');
    rect.setAttribute('rx', '6');
    rect.setAttribute('fill', visual.colorHex);
    rect.setAttribute('opacity', state.interaction.isDimmed ? '0.28' : '1');
    text.textContent = visual.label;
  },
};
```
