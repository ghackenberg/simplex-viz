## Overview & Runtime Guarantees

`@simplex-viz/core` compiles strictly against `lib: ["ES2022"]` with `"dependencies": {}`. ESLint enforces module boundaries banning `window`, `document`, SVG, or React imports inside `packages/core`.

## Imperative Engine Lifecycle (`SimplexGraphEngine`)

```ts
import {
  SimplexGraphEngine,
  createSubspaceZoomStrategy,
  createCollisionDrivenLayoutStrategy,
} from '@simplex-viz/core';

const engine = new SimplexGraphEngine({
  items,
  viewportWidth: 1200,
  viewportHeight: 780,
  visualResolver,
  renderer,
  layoutStrategy: createCollisionDrivenLayoutStrategy(),
  zoomStrategy: createSubspaceZoomStrategy({ clusterZoomMode: 'incident-star' }),
});

// Mutate items without remounting:
engine.addItems(newItems);
engine.updateItems(modifiedItems);
engine.removeItems(['id-1']);

// Coalesce multiple updates into a single minimal recomputation:
engine.batch(() => {
  engine.setMeshOptions({ sideLength: 210 });
  engine.setZoomStrategy(createSubspaceZoomStrategy({ clusterZoomMode: 'spotlight' }));
});

// Zero-relayout visual filtering ('dim' | 'hide') without moving SAT coordinates:
engine.setItemFilter((item) => item.tags.includes('geometry'), { mode: 'dim' });

// Linked-view search highlighting, programmatic focus, and camera/drill-down navigation:
engine.setHighlightedItems(['item-1', 'item-4']);
engine.focusItem('item-1', { highlight: true, hover: true });
engine.zoomToItem('item-1', { zoom: 2.2, maxDrillSteps: 4 });

// Navigate hierarchical drill-down or deterministic interactive targets programmatically:
engine.drillDownTriangle(0);
engine.drillDownCluster(clusterUid);
engine.drillUp();
engine.drillToRoot();
const targets = engine.getInteractiveTargets();
```

## Low-Level Pure Math Primitives

All internal solvers are exported as pure standalone functions:

- **Mesh & Affine Transforms**: `buildSimplexMesh`, `buildSimplexLattice`, `buildSubdividedTriangleMesh`, `buildIncidentStarMesh`, `applyZoomAffine`, `invertZoomAffine`, `composeZoomAffine`
- **Clustering, QAP & Discriminative Labeling**: `computeSimplexClustering`, `embedSimilarityMatrixOnMesh`, `partitionTagsJaccard`, `embedClustersQapAnnealing`, `completePlanarSharedTags`, `matchClustersHungarian`, `assignDiscriminativeClusterLabels`, `resolveDiscriminativeClusterLabel`, `disambiguatePeerClusterTitle`
- **Convex Geometry & SAT**: `computeConvexHull`, `rectToConvexPolygon`, `regularPolygon`, `starConvexHull`, `isPointInTriangle`, `computeConvexMtv`, `hitTestConvexGeometry`, `UniformSpatialHashGrid`
- **OKLab Perceptual Color**: `hexToOklab`, `oklabToHex`, `mixOklabColors`, `lerpOklabHex`, `generatePerceptualClusterPalette`, `assignMeshClusterColors`
