## Overview & Runtime Guarantees

`@simplex-viz/core` root and `@simplex-viz/core/worker` compile strictly against `lib: ["ES2022"]` with `"dependencies": {}`. ESLint enforces module boundaries banning `window`, `document`, SVG, or React imports inside `packages/core`. Shared browser/host helpers live on `@simplex-viz/core/dom` behind purely structural TypeScript interfaces (`SimplexDomElementLike`, `SimplexDomDocumentLike`, `SimplexDomWindowLike`) so `skipLibCheck: false` consumers without DOM `lib` entries continue to compile cleanly.

## Imperative Engine Lifecycle (`SimplexGraphEngine`)

```ts
import {
  SimplexGraphEngine,
  createSubspaceZoomStrategy,
  createCollisionDrivenLayoutStrategy,
} from '@simplex-viz/core';

const engine = new SimplexGraphEngine({
  items,
  viewportWidth: 1200,
  viewportHeight: 780,
  visualResolver,
  renderer,
  layoutStrategy: createCollisionDrivenLayoutStrategy(),
  zoomStrategy: createSubspaceZoomStrategy({ clusterZoomMode: 'incident-star' }),
});

// Mutate items without remounting:
engine.addItems(newItems);
engine.updateItems(modifiedItems);
engine.removeItems(['id-1']);

// Coalesce multiple updates into a single minimal recomputation:
engine.batch(() => {
  engine.setMeshOptions({ sideLength: 210 });
  engine.setZoomStrategy(createSubspaceZoomStrategy({ clusterZoomMode: 'spotlight' }));
});

// Zero-relayout visual filtering ('dim' | 'hide') without moving SAT coordinates:
engine.setItemFilter((item) => item.tags.includes('geometry'), { mode: 'dim' });

// Linked-view search highlighting, programmatic focus, and camera/drill-down navigation:
engine.setHighlightedIds(['item-1', 'item-4']);
engine.focusItem('item-1', { highlight: true, hover: true });
engine.zoomToItem('item-1', { zoom: 2.2, maxDrillSteps: 4 });

// Interactive multi-selection, reduced-motion preference, legend model & deep-linking view state:
engine.setSelectedIds(['item-1', 'item-2']);
engine.setShiftClickSelects(true);
engine.setReducedMotion('auto');
const legend = engine.getLegendModel();
engine.setOnLegendChange((nextLegend) => {
  console.log('Visible legend entries:', nextLegend.entries.length);
});
const viewState = engine.getViewState();
engine.restoreViewState(viewState);

// Navigate hierarchical drill-down or deterministic interactive targets programmatically:
engine.drillDownTriangle(0);
engine.drillDownCluster(clusterUid);
engine.drillUp();
engine.drillToRoot();
const targets = engine.getInteractiveTargets();
```

## Web Worker Offloading (`@simplex-viz/core/worker`)

Offload QAP annealing and SAT/PBD layout solving off the UI thread with automatic stale-generation cancellation (`SUPERSEDED` / `AbortSignal`), main-thread `TItem` reference rehydration, optional `Float32Array` `ArrayBuffer` transfers, and a pluggable `solver` hook ready for future Rust/WASM backends:

```ts
// worker.ts
import { attachSimplexWorkerHandler } from '@simplex-viz/core/worker';
attachSimplexWorkerHandler();

// main.ts
import {
  createSimplexWorkerClient,
  isSimplexWorkerCancelledError,
} from '@simplex-viz/core/worker';

const client = createSimplexWorkerClient(
  () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
);

try {
  const { snapshot } = await client.solve(items, {
    width: 1200,
    height: 780,
    clusteringStrategy: { kind: 'soft-simplex-tag' },
    layoutStrategy: { kind: 'collision-driven' },
  });
} catch (err) {
  if (!isSimplexWorkerCancelledError(err)) throw err;
}
```
