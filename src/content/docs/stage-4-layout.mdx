## Orthogonal Building Blocks (`createComposedLayoutStrategy`)

Instead of monolithic layout algorithms, SimplexViz factors layout solving into three composable interfaces:

### 1. `LayoutSeeder` (Initial Placement)
- `createPhyllotaxisSeeder()` — Places co-located items on a golden-angle Vogel spiral (`θ_n = n · 137.508°`) around their barycentric target.
- `createMeshInwardFanSeeder()` — Fans vertex-anchored items smoothly toward incident mesh sectors to maximize initial clearance before relaxation.
- `withWarmStartSeeder(seeder)` — Reuses settled coordinates from the previous frame for existing item IDs so live mutations settle with minimal visual displacement.

### 2. `PositionRelaxer` (Iterative PBD + SAT/MTV Separation)
- `createBarycentricPbdRelaxer()` — Couples a gentle spring toward each item's exact barycentric target with Separating Axis Theorem (SAT) Minimum Translation Vector (MTV) impulses accelerated by `UniformSpatialHashGrid`.
- `createSpaceFillingPbdRelaxer()` — Adds short-range electrostatic-style dispersion inside covering triangles so nodes utilize open triangle interiors evenly.

### 3. `ScaleController` (Adaptive Node Sizing)
- `createUniformScaleController()` — Binary-searches a single global `α ∈ [minContentScale, 1]`; ideal when node radius encodes a quantitative metric (e.g. citations or duration) whose global ratio must stay exact.
- `createCollisionLocalScaleController()` — Starts every item at `1.0x` and iteratively multiplies only actively colliding pairs by `shrinkFactor` (`0.85` default, bounded by `minLocalScale`). Pairs naturally with hierarchical `1:4` drill-down!
- `createDensityPriorScaleController()` — Runs a `1.0x` space-filling dispersion pass first, evaluates smooth radial crowd density within `crowdRadiusPx` (`76 px`) on the dispersed positions, and resolves any residual collisions locally with halo blending.
- `createFixedScaleController({ scale: 1.0 })` — Locks node scale at a constant factor without auto-shrinking.

## Preset & Custom Composition Example

```ts
import {
  createComposedLayoutStrategy,
  createMeshInwardFanSeeder,
  createSpaceFillingPbdRelaxer,
  createCollisionLocalScaleController,
} from '@simplex-viz/core';

const customLayout = createComposedLayoutStrategy({
  seeder: createMeshInwardFanSeeder(),
  relaxer: createSpaceFillingPbdRelaxer({
    springFactor: 0.7,
    dispersionGapPx: 18,
  }),
  scaleController: createCollisionLocalScaleController({
    minLocalScale: 0.32,
    shrinkFactor: 0.85,
  }),
  warmStart: true,
});
```
