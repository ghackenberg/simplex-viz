## Why sRGB Fails on Triangulated Meshes

Linearly averaging sRGB hex values along a mesh edge—for instance between Cyan (`#06B6D4`) and Amber (`#F59E0B`)—collapses perceptual lightness and chroma near `w = (0.5, 0.5)`, turning bridge items into dull grey-brown dots that look visually *inactive* rather than *interdisciplinary*.

SimplexViz converts cluster colors into **OKLab** `(L, a, b)`, computes the weighted barycentric sum, gently restores perceptual chroma `C = √(a² + b²)` toward the weighted mean chroma of the contributing clusters, and clamps cleanly into the sRGB gamut.

## Custom Brand Palette Example

```ts
import { createPaletteColorStrategy } from '@simplex-viz/core';

const corporatePalette = createPaletteColorStrategy(
  ['#0891b2', '#d97706', '#c026d3', '#059669', '#2563eb', '#e11d48'],
  {
    mode: 'edge-contrast',
    preserveMatchedColors: true,
  },
);
```
