## Ecosystem Topology & Discrete Stack Boundaries

This dataset contains real public repository records queried from the **GitHub REST Search API** across the data-visualization, WebGL, GPU rendering, and network-analysis ecosystem (including projects such as `three.js`, `d3`, `apache/echarts`, `visx`, `cytoscape.js`, `deck.gl`, and `pixijs`). Each repository carries normalized technology and domain topics (`#webgl`, `#threejs`, `#svg`, `#canvas`, `#charts`, `#graph`, `#rust`, `#wasm`, `#typescript`).

## Why Jaccard QAP Annealing Excels on Curated Tech Stacks

Unlike broad prose tags, software ecosystem topics exhibit sharp structural boundaries: a repository either targets `#webgl` + `#shaders`, bridges `#svg` + `#charts`, or combines `#graph` + `#canvas`.

- **Jaccard Annealing Clustering (`createJaccardAnnealingClusteringStrategy`)**: Partitions repository topics via regularized Jaccard affinity, embeds co-occurring ecosystems on adjacent 60° mesh vertices via Simulated Annealing, snaps shared dual-stack libraries onto exact 1-hop edges and triangle centroids, and disambiguates sibling hubs sharing a broad umbrella topic via `disambiguatePeerClusterTitle`.
- **OKLab Edge Contrast (`createOklabContrastColorStrategy`)**: Maximizes perceptual `ΔE_OK` across neighboring technology hubs so adjacent stacks remain unmistakable at a glance.
- **Exclusive-First Semantic 3→6 Tag Drill-Down (`createSemanticZoomStrategy`)**: Zooming into an overlapping ecosystem triangle—such as *Visualization – Data Vis – JavaScript*—ranks assigned sub-tags by **exclusivity across the 6 sibling sub-vertices** (`#graph`, `#threejs`, `#typescript`, `#webgl`) ahead of ubiquitous carrier tags (`#javascript`, `#visualization`). Refined corners render two-line context plaques (`VISUALIZATION / Graphs · JavaScript`, `DATA VIS / TypeScript`), unchanged corners remain clean single-line capsules (`JavaScript` without redundant header stutter), and sparse neighbor midpoints fall back to explicit `A ↔ B` bridge relations.
